# Tasks: The notebook in the landscape — slice `reveal`

**Input**: `slices/reveal/plan.md` (Increments 0–9, "Tests, file by file"), `research.md` (R1–R9), `data-model.md`, `quickstart.md`; `contracts/ui-shell.md` (amended by the plan); `decisions.md` D41–D45 (on D6, D29); spec FR-011 (amended), FR-012, FR-013, FR-013a, FR-018, FR-032, SC-002, SC-008, SC-009, User Story 2 scenarios 5 and 6, User Story 3, and the Clarifications block "Gaps reviewed for slice `reveal`".

**Method**: Every task is one RED-GREEN-REFACTOR increment on one rule of the plan, taken one per commit. Write the failing test, watch it fail for the reason named, make it pass, tidy, commit. Rules are numbered `R<increment>.<n>` and their examples `E<increment>.<n>.<m>`, so an implementation delegate can be handed one task, or every task of one story. No mocking framework and no new `vi.mock` (`AGENTS.md`): tests stand in at the IPC seam with `installFakeCore` (`src/screens/__tests__/fakeCore.ts`) and plain fakes; sheets and sources are read from disk through the dynamic `'node:' + 'fs'` import. Characterisation tasks (T001–T004) are green at once by design: their teeth are shown by the sanctioned break-and-restore (change the production file, run the test, `git checkout -- <exact path>`), recorded in the commit message. Every task ends with `npm test`, `npm run lint`, `npm run build` and `npm run check` green.

**Precondition, not a task**: Increment 0 (`gap: calc(4 * var(--nb-u)) calc(20 * var(--nb-u))` and `margin: calc(12 * var(--nb-u)) 0 0` in `src/styles/tonight-page.css`, research R6) is the owner's session's repair of `main` (`host/fix-tonight-units`). This slice rebases onto it and does not carry it. Do not start T001 on a tree where `npm test` is red.

**Guard**: Every word, state and control is today's (FR-018); nothing reads the clock (FR-013); no switch in a released build (FR-012, SC-002); colour only from look tokens; nothing moves (FR-023, D3). Not edited by any task: `src-tauri/`, `scripts/` (every guard), `package.json`, the lock, `Makefile`, CI, `project.json`, `src/main.tsx`, `src/navigation.ts`, every page sheet but the ones a task names, and `delivery/` beyond `delivery/survey/pinned.md` (T012). No task edits `tasks.md`.
